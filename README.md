# 台历日期校对器（Calendar Proofreader）

给平面设计师用的台历 / 日历 / 挂历**日期排版校对工具**：把转曲后的 PDF（或一张日历图片）丢进去，自动核对每一天的位置、星期列、每月天数。

**离线运行 · 不需要字体文件 · 不需要 OCR · 不需要联网 · 不需要 API Key。**

> 本仓库只包含源码与文档，**不包含任何设计稿、客户文件或渲染截图**。

---

## 它能查什么

- 漏排、重号、印错的日期（比如 17 日印成 11 日）
- 日期落在错误的星期列上（整月错位也能抓）
- 每月天数对不对（小月写成 31 天、闰年 2 月写成 28 天）
- 每格星期与真实历法是否一致

不校对：农历 / 节气的内容本身、节假日调休标记的位置。

## 它怎么认字（为什么不依赖字体）

转曲后文件里没有文字，只有矢量图形，所以它不是"读字"，而是**分组 + 反推**：

1. **切** —— 从 PDF 读矢量轮廓，先按横缝切行，再按竖缝切字
2. **分组** —— 同一个数字在文件里被画了很多次，形状几乎逐像素相同，归成一组（不需要字体）
3. **命名** —— 台历按 1、2、3… 顺序排，所以"这一格该是几号"本身就知道；全书一起投票给每组定名
4. **对账** —— 拿真实历法核对每一格的位置、星期、天数

## 支持的版式

| 版式 | 说明 |
|---|---|
| 七列网格 | 最常见的月历；有格子框就按框定位，没有就按字号分层 |
| 横排一行 | 一整月横着排成一条 |
| 横排连排 | 整月连着排、换行接着排（星期表头可能重复） |
| 图片 | PNG / JPG / 截图 / 拍照稿，自动二值化后按行列投影切字 |

遇到没见过的版式，引擎会**自动试算**（在"哪几行是日期行 / 一格多宽"上搜索），
切出来正好等于当月天数、且一位/两位分布符合历法时才认；
认对了就把几何参数存进 `profiles/*.json`，**同一款再印时直接命中档案**。
试算不过就跳过该页并说明原因——**绝不把假错误报给你**。

## 安装

```bash
python -m pip install pymupdf numpy pillow
```

需要 Python 3.9+。Windows 用户也可以直接用便携版（见下方"网页界面"）。

## 用法一：命令行

```bash
python -m calproof.cli 台历.pdf --year 2027 -o 报告.html
python -m calproof.cli 日历截图.png --year 2027
```

- `--year` 必填（年份错了整份结论都是错的）
- `--first-col auto|mon|sun` 第一列是周几，默认自动判断
- `--start-month 1` 第 1 个月历页对应几月
- 有错误时退出码为 1，属正常

## 用法二：网页界面（拖拽）

```bash
python app.py
```

浏览器会自动打开（默认 `http://127.0.0.1:8765`），把 PDF 或图片拖进去即可。
Windows 上双击 `启动校对工具.bat` 即可（需先安装依赖，或用 `install_requirements.bat` 自愈）。

## 用法三：作为 AI Agent 的 Skill

`skill/` 目录就是可直接安装的 Skill（`SKILL.md` + `scripts/` + `references/`）。

1. 把 `skill/` 整个复制到你的 Skill 目录（例如 `~/.skills/calendar-proofreader/`）
2. 让引擎就位：把仓库根目录的 `calproof/` 复制成 `skill/engine/calproof/`，
   或运行 `pwsh skill/scripts/sync_engine.ps1 -Project <仓库根目录>`
3. 依赖：`python -m pip install pymupdf numpy pillow`

之后在对话里说"帮我核一下这份台历"即可。引擎失灵时，Skill 里附了
`references/诊断手册.md`（四步归因：看体检 → 看标注图 → 看每格明细 → 改对应函数）。

## 报告怎么看

- **红框**：确定有错，框里就是错的地方
- **橙框**：机器对这一格不确定，请人看一眼
- 每个月一张图，图下是对应的错误说明

## 目录

```
calproof/            校对引擎
  extract.py           从 PDF 抠轮廓、切成字形
  layers.py            分层、七列网格（有格子框按框定位）
  linear.py            横排版式（一行 / 连排换行）
  raster.py            图片稿：二值化 + 投影切字
  profile.py           版式档案：试算学习 / 存档 / 命中
  cluster.py           形状分组 + 按位置反推数字
  check.py             校对规则
  truth.py             历法真值
  report.py            可视化报告
  pipeline.py          串起整条流程
app.py               网页界面（拖 PDF / 图片）
skill/               AI Agent 用的 Skill
profiles/            学到的版式档案（运行时生成，默认不入库）
```

## 已知限制

- **一份文件里混两套版式**（如 24 页 = 横排 12 月 + 网格 12 月）会被按页序对错月份，请分开导出
- **双月一页**、竖排周历、一格一周的周历暂不支持
- **照片质量差**（虚焦、反光、日期压在深色花纹上）会切碎字，报告里会出现成片"待确认"
- **日期印在格子外**（"24 | 31 | 25" 那种压格线写法）会被报成"缺日期"，请自行判断是否有意排版
