# 台历日期校对 · 使用说明

给平面设计师用的小工具：把转曲后的台历 PDF（或者一张日历图片）丢进去，自动核对每个日期的位置和星期是否正确。

**不需要字体文件，不需要联网，不需要 OCR 模型，不需要装设计软件，不需要懂代码。**

本仓库只包含源码与文档，**不包含任何设计稿、客户文件或渲染截图**。

---

## 一、网页版（不联网，适合批量校对）

1. 第一次用，先双击 **`install_requirements.bat`**（需联网一次，装 Python 3.12 + pymupdf / numpy / pillow，约 100MB）。
2. 双击 **`停止校对工具.bat`**❌（不存在，忽略）——正确是双击 **`启动校对工具.bat`**，会弹出黑色窗口 + 浏览器页面（窗口别关）。
3. 把 PDF（或日历图片）**拖进页面**，选好年份（第一列是周几不用选，工具自己看）。
4. 点「开始校对」，几秒后出报告。

> 现在**不需要把你的字体放进 `fonts` 文件夹**。旧版靠“字体模板匹配”，字体对不上就整本罢工；
> 现在改成按字形分组，任何字体都能读。

---

## 二、Agent Skill（在对话里直接校，适合怪版式）

这个仓库里的 `skill/` 就是一个可直接安装的校对技能。装上以后，在对话里丢一份稿子、说一句
“帮我核一下这份台历”就行。

安装（Windows）：

1. 把本仓库的 `skill/` 文件夹复制成 `%USERPROFILE%\DoubaoWork\skills\calendar-proofreader`；
2. 把仓库根的 `calproof/` 复制成 `…\skills\calendar-proofreader\engine\calproof`
   （或跑 `powershell -File skill/scripts/sync_engine.ps1 -Project <仓库根>`）；
3. 重启对话。

> 技能必须装在**用户自己的技能目录**（`%USERPROFILE%\DoubaoWork\skills`）；
> 装到平台自带的 `.skills` 里会被下次同步清掉。

两边是**同一份引擎**（结果里的 `engine` 指纹一致才说明没跑偏）。区别只有一个：

- **本地工具**：适合批量、离线、客户稿不外传；读不动只能报一句“跳过”。
- **对话里的 Skill**：读不动时 AI 能当场诊断 —— 看页面图、看每格读数和置信度、
  定位是版式没见过的哪一处、改判据、重跑，然后告诉你“这是稿子的错”还是“这是工具的盲区，已经修好了”。

## 三、命令行用法

```bash
python -m calproof.cli 台历.pdf --year 2027 -o output/report.html
python -m calproof.cli 日历截图.png --year 2027     # 图片直接读
python skill/scripts/run_check.py 台历.pdf --year 2027 --diag --png
```

`run_check.py` 会多吐一份 `result.json`：里面有体检结论（`health.need_ai`）、
每页读数、每格置信度，方便排查。

## 四、认不出来的新款式：会自己学、并且记住

遇到从没见过的版式（整月连着排、换行接着排、环形……），工具不会直接放弃：

1. **自动试算**：在“哪几行是日期行 / 一格多宽”上做小范围试算，找到一种“切出来正好等于这个月天数、
   而且一位数/两位数的分布符合历法常识”的切法；
2. **自证**：切出来的读数必须和历法对得上（绝大多数格子的读数就是它该是的那天），
   对不上就宁可跳过，也不会把一堆假错误丢给你；
3. **存档**：认对了就把这一款的几何参数存进 `profiles/`（只存位置和格距，不存截图）；
4. **下次直接用**：同一款台历再印（换照片、换文案、换开数都行），命中档案就直接校，不再试算。

所以第一次遇到新款式可能要等几秒（工具在试），第二次开始就是秒出结果。

## 五、报告怎么看

- **红框**：确定有错，框里那个位置就是错的地方
- **橙框**：机器对这一格的分组不确定，请你看一眼（很少出现）
- 每个月一张图，图下面是对应的错误说明

能自动查出来：

- 漏排、重号、印错的日期（17 日印成 11 日）、日期超范围
- 日期落在错误的星期列上（一整月错位也能抓）
- 每月天数对不对（小月写成 31 天、闰年 2 月写成 28 天）

目前**还没做**：农历小字的内容校对、节气/调休标记的位置校对、双月一页 / 周历版式。

## 六、能认哪些版式

判断日期不是靠“字体长什么样”，而是靠两件在哪儿都不变的事：
**日期是格子里最左边那 1~2 个字**，**它们按 1、2、3…顺序往下/往右排**。

- **七列网格**（最常见）。有格子框的稿子直接按框定位，日期旁边挨着节日名（立春、除夕）也不会把列挤歪
- **横排一行**：一整月 31 天横着排成一条
- **横排两行**：半个月一行，下面再排一行
  （这两种不用手动选，引擎自己判：一条横带里出现 ≥10 个等距日期槽就按横排处理）
- **直接拖图片**：JPG / PNG / 截图 / 手机拍的稿子。从像素切字，后面认形状、定名、对历法完全一样
- **有农历 / 没农历**都行。农历小字、节日名挨在日期后面也不影响，只读最左边两个
- **日期什么颜色都行**（红字周日、黑字平日、蓝字周末混排也没问题）
- **表格线、分隔线**先剔掉，不会把相邻数字串成一个
- **首行印了上个月的末尾日期**（灰色 27~31）能认出来，不会当成 1 号让整月错位
- 日期补零（`01`）和不补零（`1`）都能读

仍然认不了 / 会跳过：

- 一份文件里**塞了两套版式**（如 24 页 = 横排 12 个月 + 网格 12 个月），月份会按页序对错 —— 请分开导出
- **双月一页**、竖排周历、一格只放一个星期的周历版式
- 拍得太糊、日期压在深色花纹上的图片（会切碎字，报告里会出现一片待确认）

## 七、它为什么能认转曲的字

转曲之后文件里没有文字，只有矢量图形。所以它不是“读字”，而是**分组 + 反推**：

1. **切**：读矢量轮廓，先按横缝切成一行行，再按竖缝切成一个个字
   （CorelDRAW/AI 常把整列甚至整页文字合成一条路径，必须两级切）
2. **分层**：按字号分出层次，挑“字母表最小”的那一层——日期只有 10 种形状（0~9），
   农历小字有几十种，所以日期层一眼能认出。算字母表时**只数每格最左边那 1~2 个字形**
3. **分组**：同一个数字被画了无数次，但每次画的都是同一条路径，形状几乎逐像素相同 → 归成一组。
   **这一步完全不需要字体**
4. **反推**：台历的格子是从左到右、从上到下按 1、2、3…排的，所以“这一格该是几号”本身就知道。
   12 页一起投票，每组就被定名了
5. **对账**：拿真实历法核对每一格的位置、星期、每月天数

第 4 步是关键：不需要知道“这个形状是几”，只需要知道“这一格应该是几”。
单页可能有错，但错的那一格投不过其余 11 页，所以命名依然是准的。

## 八、常见问题

**Q：双击了没反应 / 提示找不到 Python？**
先双击 `install_requirements.bat`（会联网装好 Python 与依赖，只用一次）。
企业网络可能拦 Python 安装包，换家用网络再试。

**Q：我放了自己的字体，为什么没变化？**
现在不需要字体了，`fonts` 文件夹可以留着不管。识别走形状分组，与字体无关。

**Q：整个月都被框出来了？**
说明是“整月错位”，所有日期都往一边挪了列。报告会写清 1 号被放到了哪一列、按历法应该在第几列。

**Q：第一列是周几选错了会怎样？**
不用选，工具会把“周日开头”和“周一开头”两种都试，哪种对得多就用哪种。

**Q：页面被跳过，提示“这一页的字形太少”？**
封面、广告页、非月历版式会被自动跳过。月历页被跳过通常意味着版式没见过（走 `profiles/` 学一次）；
图片稿整页读不出，多半是分辨率太低（建议长边 1500 像素以上）。

**Q：农历小字会不会被当成日期？**
不会。一格只读最左边 1~2 个字形，后面的农历小字、节日名、休/班标记都不参与读数。

**Q：一格里有节日名，会不会读成 “244” 这种？**
不会，同上。以前读成 “244” 是旧逻辑把整格字形都拼起来了。

**Q：一本台历要跑多久？**
12 个月历页约 3 秒；30 页带封面的完整文件约 7 秒。

## 九、目录说明

```
启动校对工具.bat          双击这个（网页版入口）
install_requirements.bat  第一次用 / 环境坏了时双击这个
app.py                    网页界面（只用标准库 + 本项目依赖）
calproof/                 校对引擎
  extract.py                从 PDF 里抠轮廓、切成一个个字形
  layers.py                 分层、还原七列网格（有格子框就按框定位）
  linear.py                 横排版式（一行 / 两行连排）
  raster.py                 图片稿：二值化、按行列投影切字
  cluster.py                按形状分组
  check.py                  校对规则
  truth.py                  历法真值
  profile.py                版式档案（学习 / 存档 / 命中）
  report.py                 生成报告
  pipeline.py               串起整条流程
skill/                    Agent 技能包（SKILL.md / references / scripts）
tools/make_sample.py      生成“转曲”测试 PDF（开发 / 回归用，需 fontTools）
profiles/                 版式档案（运行时自动生成，已 gitignore）
output/                   每次跑完的报告（已 gitignore）
```

命令行也能用：

```bash
python -m calproof.cli 台历.pdf --year 2027
python -m calproof.cli 日历截图.png --year 2027
```
