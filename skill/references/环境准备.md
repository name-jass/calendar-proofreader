# 环境准备（引擎跑不起来时）

引擎只依赖三个包：`pymupdf`（读 PDF 矢量）、`numpy`、`Pillow`。
不需要 OCR、不需要联网、不需要字体文件。

## 情况 A：Windows，用便携运行时

```powershell
cd "<项目目录>"
& ".\runtime\python\python.exe" -c "import fitz;print(fitz.__doc__)"
```

`runtime\python\python.exe` 不存在 → 双击 `install_requirements.bat`，它会自愈重建。

## 情况 B：Linux / macOS

```bash
python3 -V                       # 需要 3.9+
python3 -m pip install pymupdf numpy pillow
python3 scripts/probe_env.py     # 应返回 ok=true
```

装不动（无外网 / 权限不足）时按顺序试：

1. 换镜像：`python3 -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pymupdf numpy pillow`
2. 用户级安装：`python3 -m pip install --user ...`
3. 都不行 → 如实告诉用户"这个环境装不上解析库"，**不要**假装校对过。

## 情况 C：Windows 但没有便携运行时

按顺序探测：`py -3` → `python` → 常见安装路径。

```powershell
py -3 -c "import sys;print(sys.version)"
```

注意：微软商店那个 0 字节 `python.exe` 占位符会假装存在，必须用 `-c` 实测才准。
